What GitHub has published

  • Copilot Business costs $19 per seat a month and includes 1,900 pooled AI credits per user. Copilot Enterprise costs $39 and includes 3,900.2
  • Copilot access has no seat charge for users with a GitHub Enterprise Cloud licence. Everyone else is on Copilot Standalone at $10 per user a month. Neither includes credits, so usage is billed from the first use.1
  • One AI credit is $0.01, and usage beyond a pooled allowance is billed at that rate.3
  • The billing model applies to the whole enterprise. Copilot access can't be mixed with Copilot Business or Copilot Enterprise seats.1
  • Copilot access has the same feature and model eligibility as Copilot Enterprise.1
  • Moving is voluntary. It is arranged through a GitHub or Microsoft account team, has been available that way since 28 October 2026, and takes effect on the first day of a month. It isn't yet open to customers who manage their own subscription.1

What this estimate assumes

These are our assumptions, not statements from GitHub.

  • Usage stays the same after you move. Copilot Business customers gain Copilot Enterprise model eligibility, which may push usage up.
  • Prices are list prices in US dollars, before tax, with no negotiated discount unless you change the rates.
  • GitHub Enterprise Cloud licence costs are left out, because they are the same on both sides.
  • Copilot code review also uses GitHub Actions minutes.3 Those aren't included.
  • Every seat is counted for a full month.

Before you move

Steps GitHub lists for a voluntary transition.1

  1. Set budgets, using this estimate as the baseline and allowing for growth in users or usage.
  2. Keep the "AI credits paid usage" policy enabled in your enterprise's AI Controls. Features that consume credits stop working without it.
  3. If your firewall only allows *.business.githubcopilot.com, add *.enterprise.githubcopilot.com.
  4. Assign Copilot seats. Users don't get Copilot automatically, even with a GitHub Enterprise Cloud licence.
